# صائد النجوم - HTML Game 🔊
لعبة HTML/CSS/JavaScript متجاوبة للهاتف والتابلت والكمبيوتر.

## التشغيل
افتح `index.html` في المتصفح، أو استخدم Live Server داخل Visual Studio Code.

## التحكم
- الكمبيوتر: الأسهم ← → أو A / D
- الهاتف والتابلت: اسحب إصبعك لتحريك السلة

## الأصوات
اللعبة تحتوي على مؤثرات صوتية مولدة داخل المتصفح:
- ⭐ جمع النجمة
- 💣 القنبلة
- ❤️ خسارة حياة
- 🎉 بدء/انتهاء اللعبة
- 🔊 زر كتم وتشغيل الصوت

لا توجد ملفات صوت خارجية، لذلك المشروع يعمل بدون إنترنت بعد فتحه.
